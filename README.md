# Enterprise Windows Server & Active Directory Infrastructure on AWS

## 📌 Overview

Built an enterprise-style Windows Server environment on AWS using **Windows Server 2022, Active Directory, DNS, Group Policy, and File Sharing**.

## 🏗️ Environment

* AWS EC2 + VPC
* DC01 — Domain Controller + DNS + GPO + File Server
* CLIENT01 — Domain-joined Windows system
* Domain: `corp.local`
* RDP secured using My IP

## 🔧 Key Tasks

* Installed and configured Active Directory Domain Services
* Created OUs, users, and security groups
* Configured DNS for `corp.local`
* Created `Corporate-Security-Policy` GPO
* Joined CLIENT01 to the domain
* Configured departmental file shares and permissions
* Performed Windows/DNS/domain troubleshooting

## 🛠️ Technologies

**AWS EC2 | AWS VPC | Windows Server 2022 | Active Directory | DNS | Group Policy | RDP | NTFS | TCP/IP**


## ✅ Outcome

Demonstrates practical skills in **Windows Server Administration, Active Directory, IT Infrastructure, Cloud Administration, and Troubleshooting**.
